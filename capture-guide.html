캡처 101건회차 30개컷 지침 84컷

1. 시작 전에

✅ 준비

  • 일반 창 + 시크릿 창 둘 다 띄움
  • 테스트몰 또는 마스킹 처리된 운영몰 결정
  • 저장할 폴더 정하기
  • Win+Shift+S 한 번 테스트

⚠ 꼭 가릴 것

  • 실제 매출·주문번호·회원정보·연락처는 가린다(검정 사각형 또는 흐림)
  • 정산 명세 금액은 반드시 가린다
  • 금액 (실제 정산 금액·계좌·VAT)
  • 실명·사업자번호·전화번호
  • 카드번호·계좌번호 (마지막 4자리 외 모자이크)
  • 다른 셀러의 정보가 비치는 경우

📐 해상도

  • PC 화면: 1920×1080 이상
  • 모바일: 1080×2400 세로
  • 화면 녹화: MP4 · 60fps · 소리 끔

2. 캡처 방법 (Windows 11)

📸 영역 캡처

Win + Shift + S
  1. 영역 드래그
  2. 오른쪽 위 알림 클릭
  3. 다른 이름으로 저장 (PNG)

🖼 전체 화면

Print Screen
  1. 그림판 열기
  2. Ctrl + V
  3. Ctrl + S (PNG)

🎥 화면 녹화

Win + G
  1. Xbox Game Bar → 캡처 위젯
  2. 빨간 원으로 녹화 시작·중지
  3. 동영상 › 캡처 폴더에 저장됨
